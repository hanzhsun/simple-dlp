# YouTube 片段下载器

带简单图形界面的 YouTube 片段下载工具。调用本机已安装的 **yt-dlp** 和 **ffmpeg**，输出 **H.264 + AAC** 的 MP4，方便导入剪映 / CapCut。

## 功能

- 选择保存文件夹、粘贴 YouTube 链接
- 按起始 / 结束时间添加多个片段，一次下载
- 画质上限 **2K（1440p）**，再转码为剪映友好编码
- 可选下载字幕，并按片段起始时间裁切（时间轴从 `00:00` 开始）
- 进度条、日志输出、一键复制日志

## 环境要求

1. **Python 3.10+**（本程序界面使用 PySide6，不依赖系统 tkinter）
2. **yt-dlp**（命令行可用）
3. **ffmpeg**（命令行可用，建议同目录带有 `ffprobe`）

检查是否安装成功：

```bash
yt-dlp --version
ffmpeg -version
```

## 安装与启动

```bash
# 安装界面依赖
pip install -r requirements.txt

# 启动
python dlp.py
```

Windows 也可双击 `启动下载器.bat`（若缺少 PySide6 会尝试自动安装）。

## 使用说明

1. 选择**目的文件夹**
2. 粘贴 **YouTube 视频链接**
3. 填写**起始时间**、**结束时间**（如 `5:38` / `6:58`，也支持秒数）
4. 点击**添加片段**（可添加多个）
5. 按需勾选**下载字幕**
6. 点击**开始下载**

输出示例：

- 视频：`clip_01_5-38_6-58.mp4`
- 字幕（若开启）：`clip_01_5-38_6-58.en.srt` 等

日志中会显示将下载的源画质，以及成品分辨率 / 编码信息。

## 输出规格

| 项目 | 说明 |
|------|------|
| 容器 | MP4 |
| 视频 | H.264（libx264，CRF 18） |
| 音频 | AAC 192 kbps |
| 分辨率上限 | 1440p（2K） |
| 其它 | `+faststart`，便于剪辑软件读取 |

## 依赖

见 `requirements.txt`：

- `PySide6` — 图形界面

`yt-dlp` / `ffmpeg` 需自行安装到系统 PATH，或放在本程序同一目录（也可放在 `bin/` 下）。

## 常见问题

**提示找不到 yt-dlp / ffmpeg**  
把对应可执行文件加入 PATH，或放到与 `dlp.py` 同一文件夹。

**下载很慢 / 转码久**  
会先下最高不超过 2K 的源流，再转成 H.264；片段越长、源码率越高，耗时越久。

**没有字幕文件**  
该视频可能没有人工或自动字幕；或未勾选「下载字幕」。
